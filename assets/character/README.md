# キャラ「アリス」基準画像の置き場所

このフォルダに **アリスの顔写真（基準画像）** を置いてください。
`src/generate.mjs` がここの画像を読み、**毎回同じ顔・髪型・雰囲気**でシーンだけ変えた画像を作ります。

## 置き方

- ファイル名は何でもOK（`miu-01.png` など）
- 対応形式: `.png` / `.jpg` / `.jpeg` / `.webp`
- **1枚でも動きます。** 2〜4枚あると一貫性がさらに安定します

## おすすめの用意（2〜4枚）

1. **正面・顔がはっきり写ったバストアップ**（最重要・必須）
2. 斜め45度の顔
3. 全身または上半身（服装・体型の基準）
4. 自然な表情ちがい（笑顔など）

## 画像はどう作る？

- `character-bible.md` のアリスの設定に合わせて、一度だけ基準画像を生成 or 用意する
- この環境の画像生成ツールで「アリスの基準顔」を作ることもできます（希望あれば作成します）

## 注意

- このフォルダの画像は**リポジトリにコミットされます**（顔の一貫性のため公開されてOKなもののみ）
- 実在人物の写真を無断で使わないこと（権利・なりすまし防止）
